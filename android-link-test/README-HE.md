# MFIX Link Test – Android

אפליקציית בדיקת תקשורת בלבד בין MFIX לבין יש חשבונית 7.8.6.

## מה היא עושה
- בודקת אם החבילה com.app.yeshinvoice מותקנת.
- פותחת את האפליקציה הרשמית.
- שולחת הודעת ACTION_SEND מסוג text/plain עם נתוני מכירת דוגמה.
- מציגה יומן מקומי של פעולות Android.

## מה היא לא עושה
- אינה מפיקה חשבונית או קבלה.
- אינה מתחברת לחשבון או קוראת מידע פרטי.
- אינה מוכיחה שהאפליקציה מייבאת את הטקסט למסמך. נדרש ניסוי על הטאבלט.

## בניית APK
GitHub Actions בונה APK debug בכל push לתיקיית android-link-test וכן בהפעלה ידנית.
הקובץ יופיע כ-artifact בשם MFIX-Link-Test-debug-apk.
